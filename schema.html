The map

Twenty-one tables in four groups. Border colour is who may write: orange for Python, petrol for Laravel, crimson for the two both insert into and neither updates. The highlighted path is the one that matters: a fetch produces a claim, a claim is about a subject, and a subject becomes a business, a place and a class.

Lines are foreign keys. Cardinality and delete behaviour are in Relations below, where they can be read exactly rather than inferred from a diagram.

-- A claim whose value is absent from its evidence cannot be stored.
-- Python already refuses to construct one; this catches the bug in Python.
CREATE FUNCTION claims_evidence_check() RETURNS trigger AS $$
BEGIN
  IF position(NEW.value in NEW.evidence) = 0 THEN
    RAISE EXCEPTION 'claim value % is not present in its evidence', NEW.value;
  END IF;
  RETURN NEW;
END;
$$ LANGUAGE plpgsql;

Why no ad network

This is a children's-activities site. Behavioural ad tech aimed at a service about children's activities is regulatory exposure nobody needs — COPPA and CCPA both bite. Contextual placement by city and category needs no profile of anybody.

SEO is a contracted deliverable. Third-party ad scripts are the most reliable way to destroy LCP and CLS, and Core Web Vitals are a ranking signal — we would be selling ad space by damaging the asset it is sold against.

Brand safety. Direct-sold slots mean nothing inappropriate appears beside a children's class. An ad network cannot promise that.

Where subscriptions and ads meet

ads_free is an entitlement, so the renderer checks the viewer's plan before filling a slot. That single interaction is why the two were designed in one pass rather than separately.

Gates and rules

GateBusinessClassHub
Publishable
users see it		 name + publishable location name + parent publishable always
Indexable
search engines see it		 name + coordinates + (phone or website) + description name + age range + description + (days or dates) + parent indexable ≥3 indexable listings + an intro

Missing values display as "Unknown" and rank a listing down. They never filter it out — a directory that hides incomplete listings is empty at launch, which is when it most needs to look populated.

The class gate is meant to be hard to pass

Dates measured 0% across every source class, so most classes will not be indexable at launch. That is the intended outcome: they stay visible to users inside the business listing, and stay out of the index until they are worth indexing. A class page carrying only a name is the thin, near-identical page that gets directory sites judged poorly.
